# 이현호 개발 포트폴리오

작문과제 06을 위한 정적 개인 포트폴리오입니다. 대표 프로젝트는 **동넷**이며, 개인 담당 범위인 백엔드 API·AWS 인프라·도메인 연결과 팀 전체의 결과를 구분합니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 열거나 이 폴더를 정적 HTTP 서버로 제공합니다. GitHub Pages는 `main` 브랜치 루트(`/`)를 게시하도록 설정합니다. `.nojekyll`을 포함합니다.

- 개인 담당 범위는 작성자 확인 내용입니다. 세부 코드의 단독 저작을 주장하지 않습니다.
- `dongnet.kr`은 작성자 확인에 따라 서버와 DNS 연결이 중단된 기존 주소로 표시했습니다. 이 포트폴리오의 화면 갤러리는 실제 저장소 화면 자료를 보여 주며, 실행 중인 서버나 실시간 API 데모를 가장하지 않습니다.

## 자료와 글꼴

`assets/*webp`는 동넷 팀 프로젝트의 `docs/app` 공개 화면 자료입니다. 출처 링크는 페이지에 표시했습니다. 화면에 포함된 지도와 서비스 표시는 원본 그대로 유지했습니다. 별도의 사용 허가나 공개 라이선스를 임의로 부여하지 않습니다.

`NanumMyeongjo-Regular.ttf`는 SIL Open Font License에 따라 포함했으며 라이선스는 `assets/OFL.txt`에 있습니다. 나머지 글꼴은 운영체제 기본 글꼴입니다. 외부 분석 스크립트, 쿠키, API 키를 사용하지 않습니다.

이력서는 확인된 이름·GitHub·관심 분야·프로젝트 담당 범위로 작성했습니다. 학번, 전화번호, 이메일 등 추가 개인정보는 포함하지 않았습니다.

## 구성

- `index.html`: 소개, 프로젝트, 기여, 기술 구조, 결과와 링크
- `style.css`: 반응형 레이아웃과 모션 감소 설정
- `app.js`: 구조 설명 전환, 갤러리 조작, 점진적 진입 효과
- `assets/resume.pdf`: 다운로드 가능한 1페이지 이력서

JavaScript 없이도 전체 구조 설명과 자료를 읽을 수 있습니다. 화살표 버튼과 구조 선택 버튼은 JavaScript가 실행될 때만 표시됩니다.
